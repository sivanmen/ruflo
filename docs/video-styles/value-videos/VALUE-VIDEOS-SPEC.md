## 0. איך משתמשים במסמך הזה (הוראה לקלוד)

כשהמשתמש כותב **"צור סרטון ערך בנושא ___"**:
1. קרא את כל המסמך הזה. סעיפים 3–10 הם חוקים, לא המלצות.
2. אסוף בריף (סעיף 2). מה שלא נמסר: קבע ברירת מחדל סבירה ואמור במשפט אחד מה הנחת. אל תעצור לשאלות אם אפשר להתקדם.
3. כתוב תסריט לפי נוסחת 10 הביטים (סעיף 3) והצג למשתמש לאישור מהיר, **לפני** שמוציאים קרדיטים על קריינות.
4. אחרי אישור: קריינות → תזמוני מילים → בניית סצנות מתוך ספריית הארכיטייפים (סעיף 6) → אודיו → רינדור → QA → מסירה (סעיף 13).
5. דווח בעברית, קצר ועובדתי. אל תוציא קרדיטים מעבר לתקציב (סעיף 12) בלי אישור.

## 1. מה זה "סרטון ערך"

- **פורמט:** רילס אנימציה (Motion Graphics) אנכי 9:16, 1080×1920, 30fps, באורך 50–60 שניות.
- **אין צילום של אדם מול מצלמה.** הכול גרפיקה, טיפוגרפיה קינטית, תמונות נכסים עם תנועת מצלמה, וקריינות.
- **סגנון:** יוקרתי ושקט אבל עם קצב. נייבי עמוק, זהב, זכוכית (Glass), פינות מעוגלות. "בנק פרטי פוגש אינסטגרם".
- **מטרה עסקית:** לידים. כל סרטון מסתיים בקריאה לפעולה לוואטסאפ.
- **מבנה רגשי:** שאלה שפוגעת בכאב או בהזדמנות → סיפור קצר של דמות → תפנית → הפתרון של סיון השקעות → יתרונות → סקרנות ("כמה?" / "איך?") → CTA.

### חוקי כתיבה
- פנייה בגוף שני, בלשון זכר כברירת מחדל (כמו המקור). משפטים של עד 10 מילים.
- מילה אחת בכל משפט היא "מילת הזהב" שתודגש בזהב על המסך (מרוויח / בהכול / ביוון / נשאר / רק / מפתח / מתוגמל).
- אין הבטחות תשואה, אין "מובטח", אין מספרים לא מאומתים. נדל״ן הוא תמיד "ביוון ובכרתים".
- אסור לחשוף את התגמול/המחיר בסרטון. הסקרנות היא מנוע הלידים.
- **ניסוח לקריינות (TTS):** לכתוב "נדל״ן" ולא "נדלן". שם המותג "סיון השקעות". שלוש נקודות או נקודה = עצירה דרמטית ("דירה. ביוון.").
- תיקוני תמלול חוזרים (להפעיל על הכתוביות): סיוון→סיון · נדלן→נדל״ן · בכרטים/בכריתים→בכרתים · סוכם→סוכן · בהכל→בהכול · בחניה→בחאניה · אינוויסט→אינבסט.

## 4. שפה גרפית (Brand Tokens)

### צבעים

--navy:  #0E1E3A;   /* רקע עיקרי */

--gold2: #E8CD86;   /* זהב בהיר להדגשות טקסט */
--cream: #FAF7F1;   /* טקסט ראשי / מסגרות */
/* גרדיאנט זהב "מתכתי" לכותרות סריף: */
linear-gradient(100deg,#d9b55e 0%,#fbe7ad 35%,#e0bd66 55%,#fff6d8 70%,#d9b55e 100%)  /* background-size:200%, מונפש ב-background-position = ברק עובר */
/* אדום עדין ל-✗ בלבד: */ #e06a6a
/* ירוק וואטסאפ – רק באייקון, לא כצבע מותג */

### טיפוגרפיה (Google Fonts, OFL)

| גיבוי | Heebo | – | – |

### צורות ורכיבים
- **פינות מעוגלות בכל מקום:** כרטיסים 34px, טלפון 70px, פילים/כפתורים 999px, אייקון-בוקס 28px.
- **כרטיס זכוכית (Glass):** גרדיאנט לבן 14%→5%, `backdrop-filter: blur(18px)`, מסגרת 1.5px בזהב שקוף 35%, צל `0 20px 60px rgba(0,0,0,.35)`.
- **פיל (Pill):** מסגרת זהב 2px, טקסט זהב בהיר, רקע נייבי 55%.
- **אייקונים:** קו (stroke) 2px, פינות מעוגלות, בסגנון Lucide, inline SVG. בתוך ריבוע זהב (אייקון נייבי) או ישירות בזהב.
- **אסור:** אימוג'ים (לא מרונדרים טוב), צבעים מחוץ לפלטה, פינות חדות, פונטים אחרים.

### שכבות רקע קבועות (בכל הסרטון)
1. **רדיאל נייבי** (‎#16294d במרכז → ‎#050c18 בקצוות).
2. **בוקה זהב**: 46 חלקיקים עגולים מטושטשים שעולים לאט ומנצנצים (שקיפות 5–27%).
3. **גריין** (רעש פילם) 7% במצב overlay.
4. **וינייטה** כהה בקצוות.
5. **Light leak** (הבזק אור חם) רק ברגעי מעבר.

### לוגו
- הלוגו הלבן (wordmark "SivanInvest GROUP"), קובץ `logo.png` (960×160, שקוף).
- **קבוע** במרכז למעלה: top 150px, רוחב 300px, שקיפות 92%. מוסתר כשהלוגו מופיע גדול (סצנת הפתרון וכרטיס הסיום).
- בסצנת הפתרון: לוגו גדול (800px) עם **הבזק זהב שעובר דרך האותיות** (mask של הלוגו עם גרדיאנט נע).

### אזורים בטוחים (Reels)
- תוכן חשוב רק בין **y=250** ל-**y=1450**.
- כתוביות: מרכז ב-y≈1480. מתחת ל-1570 מסתתר ממשק אינסטגרם.
- שוליים צדדיים: לפחות 70px.

## 5. שפת תנועה (Motion Language)

| אלמנט | אנימציה | משך | Easing |
|---|---|---|---|
| מילה רגילה | עולה 60px + פייד + ביטול blur 8px | 0.5ש׳ | easeOutExpo |
| מילת זהב ("slam") | scale 1.9→1 + blur 10→0 + פייד מהיר | 0.45ש׳ | easeOutExpo |
| כרטיס / פיל | scale 0.5→1 עם overshoot | 0.45–0.55ש׳ | easeOutBack |
| כרטיס הוק | נכנס מהצד (לסירוגין ימין/שמאל) עם סיבוב 6° | 0.45ש׳ | easeOutExpo |
| וי (✓) | ציור קו (stroke-dashoffset) + הילה זהב | 0.35ש׳ | easeOutExpo |
| קווים ומסלולים | ציור קו | 0.4–0.8ש׳ | easeInOutCubic |
| תמונות רקע | Ken Burns: scale +8–12% והזזה של 20–30px לאורך הסצנה | כל הסצנה | ליניארי |
| מעבר סצנה (ברירת מחדל) | יוצאת: zoom 1→1.25 + blur 18 + פייד; נכנסת: 0.86→1 + blur 14→0 | 0.4–0.5ש׳ | easeInOutCubic / easeOutExpo |
| רעידת מצלמה | ±7px, דועכת תוך 0.25ש׳, **רק** על כרטיסי ההוק | – | – |
| ברק זהב | background-position של הגרדיאנט נע פעם אחת | 0.8–1.2ש׳ | ליניארי |

**חוקים:**
- כל אלמנט נכנס **מסונכרן למילה** שהקריין אומר (לפי תזמוני Whisper), עד 0.15ש׳ לפני המילה.
- אף פעם לא יותר מ-3 אלמנטים זזים בו-זמנית.
- בכל סצנה יש "רגע וואו" אחד בלבד.
- בכל 3–5 שניות משהו חדש קורה על המסך (שימור צפייה).

## 9. סאונד

### מוזיקה (סינתזה מקומית, חינם, `audio.py`)
- 96BPM, מהלך **Am – F – C – G**, 2 תיבות לאקורד.
- שכבות: פד (סינוסים מנוטרלים) מההתחלה · ארפג'יו פלאק בשמיניות מ-5ש׳ · קיק רך + היי-האט + בס מ-9ש׳.
- **דרופ**: כל התופים יוצאים בביט L (‎~47ש׳) עד "כמה?" כדי לבנות מתח. בסיום: אקורד Am מתנפח.
- שדרוג בתשלום (רק באישור): `elevenlabs_music_v2_5`, 48ש׳, instrumental, כ-7 קרדיטים. פרומפט: *"Elegant cinematic Mediterranean corporate, warm piano, soft strings, subtle bouzouki accents, minimal modern beat, luxurious and trustworthy, builds to uplifting finale"*.

### מפת אפקטים (SFX)
| אירוע | צליל |
|---|---|
| כל מעבר סצנה | whoosh (רעש מסונן, 0.7ש׳) |
| כרטיסי הוק | hit נמוך + whoosh קצר |
| מילות slam | hit (סינוס יורד 165→45Hz + קליק) |
| ✓ בצ'קליסט | ding (1320Hz, עולה טון בכל וי) |
| שלבי ציר הדרך | ding (1046Hz, עולה טרצה) |
| בועות/כרטיסים/צמתים | pop (900→300Hz, 0.12ש׳) |
| פורטל | whoosh ארוך (1.1ש׳) |
| לפני "כמה?" | riser 1.6ש׳ (סוויפ עולה + רעש) |
| "כמה?" | boom (38Hz) + 22 צלצולי מטבעות |
| לחיצת יד בסיום | pop + ding |

### מיקס (ffmpeg)
```bash
ffmpeg -i vo.mp3 -i music.wav -i sfx.wav -filter_complex \
"[0:a]aresample=44100,pan=mono|c0=c0,apad=whole_dur=56.5,highpass=f=80,acompressor=threshold=-18dB:ratio=3,volume=1.6[v];\
[v]asplit[v1][v2];[1:a]volume=0.32[m];[m][v2]sidechaincompress=threshold=0.03:ratio=6:attack=20:release=350[md];\
[2:a]volume=0.55[s];[v1][md][s]amix=inputs=3:normalize=0,alimiter=limit=0.95,aformat=channel_layouts=stereo" -t 56.5 mix.wav
# בחיבור הסופי: -af loudnorm=I=-14:TP=-1.5:LRA=11
```

## 11. פייפליין הפקה (טכני)

**מנוע:** דף HTML אחד (`reel.html`) עם פונקציה `render(t)` דטרמיניסטית שמציירת כל פריים לפי זמן. Playwright/Chromium מצלם פריים-פריים ל-ffmpeg.

```
build/a/          ← reel.html + logo.png + fonts *.ttf + תמונות p*.jpg
build/snap.js     ← פריימים בודדים לבדיקה:  node snap.js 1 4.6 7.9 ...
build/sheet.py    ← גיליון מגע מהפריימים
build/render.js   ← רינדור מלא 30fps → video.mp4 (כ-5 דק׳ ל-56ש׳)
build/audio.py    ← music.wav + sfx.wav (לעדכן את זמני האירועים לכל סרטון)
vo/trw.py         ← תזמוני מילים
```

### שלבים
1. **הכנה:** `pip install faster-whisper`. פונטים מ-`raw.githubusercontent.com/google/fonts/main/ofl/...`, לוגו ותמונות לתיקייה `a/`.
2. **תסריט → אישור משתמש.**
3. **קריינות** (סעיף 8) → `vo.mp3` → `ffmpeg -ac 1 -ar 16000 vo.wav` → `python3 trw.py vo.wav words.json`.
4. **בניית סצנות:** לשכפל את `reel.html`, ולכל סצנה לעדכן:
   - את מערך `SC` (חלונות זמן: כניסה מעט לפני המילה הראשונה, יציאה אחרי האחרונה, חפיפה של 0.15ש׳)
   - את `data-t` של כל מילה לפי `words.json`
   - את זמני הפונקציות `S1..S10`
   - את מערך `SUBS` של הכתוביות (עם תיקוני התמלול)
5. **הגשה מקומית** (חובה, אחרת שגיאת CORS ב-mask של הלוגו): `cd a && python3 -m http.server 8765`.
6. **Preview:** `node snap.js` על 15–20 נקודות זמן + `sheet.py`. לבדוק לפי ה-QA, לתקן ולחזור.
7. **אודיו:** לעדכן את רשימות הזמנים ב-`audio.py` → להריץ את המיקס (סעיף 9).
8. **רינדור:** `node render.js` (ברקע) → `video.mp4`.
9. **חיבור:** `ffmpeg -i video.mp4 -i mix.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 192k -af loudnorm=I=-14:TP=-1.5:LRA=11 -shortest -movflags +faststart FINAL.mp4`
10. **גרסאות מסירה** (סעיף 13).
