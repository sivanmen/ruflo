## 7. פייפליין (שונה מסרטוני ערך: שתי שכבות)

1. **רקע:** `bg.mp4`. שרשור קטעי וידאו וסטילס (עם Ken Burns) לפי זמני הסצנות, עם xfade, ב-ffmpeg.
2. **שכבת גרפיקה:** `ov.html` עם רקע שקוף. `render(t)` מקבל אובייקט זמנים `T` (‏s1b, s2a… w1, w2, w3, c1, c2, c3, one, e1).
3. **רינדור:** `render2.js` מצלם PNG שקוף (‏`omitBackground:true`) ומבצע ‏ffmpeg overlay על bg.mp4.
4. **בדיקה:** `snap2.js` לפריימים בודדים של השכבה + הרכבה על פריים רקע.
5. **אודיו:** קריינות (עם הפסקה) + מוזיקה (סינתזה מקומית או ElevenLabs באישור) + SFX עדינים (whoosh במעברים, ‏shimmer בלוקאפ, ‏ding עדין בצ׳יפים) → מיקס → loudnorm ‎-14 LUFS.
6. **QA + מסירה** (כמו VALUE-01): קובץ מלא ל-GitHub (קישור raw לצפייה והורדה), תצוגה מקדימה קטנה מ-3MB ל-Drive.
