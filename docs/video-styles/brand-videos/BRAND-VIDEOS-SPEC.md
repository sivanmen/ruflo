## 0. הוראה לקלוד: מה לעשות כשמבקשים "סרטון תדמית"

כשהמשתמש כותב **"צור סרטון תדמית על ___"** (מודל, מסלול, פרויקט, שירות או אזור):
1. קרא את כל המסמך הזה. **סעיפים 2–10 הם חוקים מחייבים.**
2. אסוף בריף (סעיף 2). מה שחסר: קבע ברירת מחדל לפי המסמך, ואמור במשפט מה הנחת.
3. הצג למשתמש **תסריט + רשימת שוטים** לאישור, לפני שמוציאים קרדיטים.
4. אחרי אישור: קריינות → מוזיקה → תזמונים → רקע → שכבת גרפיקה → מיקס → רינדור → QA → מסירה (סעיף 12).
5. כל הודעה למשתמש בעברית, קצרה ועובדתית. אל תוציא קרדיטים מעבר לסעיף 11 בלי אישור.

## 12. פייפליין הפקה

```
build/a/      ov.html + logo_w.png + פונטים (Assistant, Cormorant, FrankRuhlLibre) + p_ks2.jpg, p_int.jpg + gen_tavern.png
build/seg/    קטעי רקע 1080×1920 מטופלים בצבע
build/bg.mp4  שרשור xfade + grain + vignette
build/T.json  זמני הסצנות לשכבת הגרפיקה
```
1. **חומרים:** הורדה מ-Drive (סעיף 5). חיתוך וידאו ל-9:16: `crop=ih*9/16:ih:iw*X:0` ואז scale/crop ל-1080×1920 ו-fps=30.
2. **תסריט → אישור.**
3. **קריינות** → `vo.mp3` → ‏`trw.py` → `words.json`. **מוזיקה** → `music.mp3`.
4. **זמנים:** לחשב את כל ערכי `T.json` לפי המילים (סעיף 3; ‏A=2.0 לחלק 1, ‏B לחלק 2).
5. **רקע:** `build_bg.sh` מייצר את הקטעים (vseg לווידאו, lstill לסטילס) ומשרשר ב-xfade. לכל קטע: `אורך = (סוף−התחלה) + 0.6`, ו-`offset = נקודת_חיתוך − 0.3`.
6. **שכבת גרפיקה:** `ov.html` (רקע שקוף). להחליף את טקסטי הכותרות, הכרטיסים, הצ'יפים, המילים החושיות וה-CTA.
7. **בדיקה:** `python3 -m http.server 8766` בתוך `a/` → ‏`node snap2.js T.json 1.2 3.2 …` → הרכבה על פריים רקע → גיליון מגע → תיקונים.
8. **רינדור:** `node render2.js D T.json bg.mp4 video.mp4` (‏PNG שקוף + overlay; ‏כ-8 דק׳ ל-40ש׳).
9. **מיקס + חיבור** (סעיף 9) → `FINAL.mp4`.
10. **מסירה:**
    - GitHub `examples/<name>/` (קישור blob לצפייה + קישור raw להורדה)
    - Drive תיקייה "קלוד" `1XSIV03P3l1EpZbRaK8MJF8buCnYOUtgc`: תצוגה מקדימה ‎540×960 מתחת ל-3MB (מגבלת הקונקטור)
