## Adding new media

1. Put the original in the Drive folder that matches the subject.
2. Export to WebP: `convert in.jpg -resize "1600x1600>" -quality 78 name-1600.webp` and the same with `800`.
3. Copy both files to `src/assets/img/`, reference the stem (`name`) in `src/config/site.mjs` or the content JSON, and add a row here.
