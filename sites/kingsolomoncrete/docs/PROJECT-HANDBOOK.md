## 4. אבטחה (בדיקה מ־10.11.2026)
- **אין סיסמאות או מפתחות בקוד.** האתר סטטי, ואין בו מסד נתונים או ממשק ניהול.
- כל 143 הקבצים בשרת זהים לבנייה (בדיקת hash). אין סקריפטים זרים; הסקריפט היחיד הוא `/assets/js/main.js`.
- חסומים (403): `.htaccess`, `.git`, `.env`, קובצי גיבוי, ini, log, zip, sql, md, `api/storage`, `api/lead-i18n.json`, כל קובץ ב־`api/` חוץ מ־lead.php, ורשימות תיקיות.
- ניסיונות XSS ו־path traversal בכתובת נחסמים.
- כותרות: HSTS, CSP עם hash לסקריפטים, nosniff, X-Frame-Options, Referrer-Policy, Permissions-Policy, COOP.
- `/.well-known/security.txt` לדיווח על בעיות אבטחה.
- הטופס בודק את מקור הבקשה, מגביל קצב ומסנן בוטים.

## 7. אופן הבנייה

### 7.1 מבנה
| נתיב | תפקיד |
|---|---|
| `build/` | מחולל האתר (Node, בלי תלויות) |
| `content/<lang>/*.json` | כל הטקסטים לפי שפה |
| `data/config.json` | דומיין, שפות, פרטי קשר, נמעני לידים, פרטי החברה, מזהי מדידה |
| `data/project.json` | וילות, סטטוסים, שטחים, מפלסים, גלריה |
| `static/` | CSS, JS וטופס ה־PHP |
| `scripts/` | תמונות, גופנים, מפה, בדיקת איכות, כלי העלאה (`scripts/deploy/`) |
| `dist/` | האתר המוכן (לא ב־Git, נוצר בבנייה) |
| `assets-src/` | קובצי מקור (לא ב־Git) |

### 7.2 פעולות שוטפות
- **שינוי סטטוס וילה:** `data/project.json`, שדה `status`.
- **שינוי טקסט:** `content/<lang>/<file>.json`, אותו מפתח בכל 9 השפות.
- **מזהי מדידה:** `data/config.json` תחת `tracking` (נטענים רק אחרי הסכמה לעוגיות).
- **בנייה ובדיקה:**

```bash
cd sites/kingsolomoncrete && npm run build && npm run check
```

### 7.3 העלאה לשרת
1. בונים ובודקים (0 בעיות).
2. אורזים את `dist/` לקובץ zip.
3. מעלים בעזרת `scripts/deploy/push.sh` אל קובץ הקליטה בשרת. הקובץ מוגן בטוקן; שם הקובץ והטוקן נמצאים רק במסמך הפרטי ב־Drive.
4. בודקים את האתר החי (sitemap, טופס, כותרות אבטחה).
5. כדי לבטל את אפשרות ההעלאה מרחוק, מוחקים את קובץ הקליטה מ־File Manager.
