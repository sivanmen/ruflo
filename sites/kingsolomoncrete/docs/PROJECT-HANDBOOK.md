## 2. נתוני הפרויקט

### 2.1 עובדות מפתח
- 21 וילות פרטיות, בריכה פרטית בכל וילה, קו ראשון לים על צוק.
- 34 מ׳ מעל פני הים, 70 מ׳ מרחק אווירי לים, נוף ים פנורמי של כ־270°.
- גישה ישירה לים: כ־30 עד 40 מדרגות לחוף, לטיילת ולטברנות של קליבס.
- מתחם סגור ומאובטח: שלוש כניסות מבוקרות, מצלמות, זיהוי פנים, כניסות נפרדות לווילות.

### 2.2 מרחקים
- מרכז הכפר קליבס: 2 דק׳ · נמל סודה: 8 דק׳ · העיר העתיקה של חאניה: 12 דק׳ · שדה התעופה של חאניה: 22 דק׳.
- זמני טיסה לחאניה (לפי המצגת): ישראל 1:30, רומניה 1:45, הונגריה 2:00, אוקראינה 2:10, צ׳כיה 2:25, פולין 2:45, בלארוס 2:45, צרפת 3:10, רוסיה 3:30, הולנד 3:35, פינלנד 3:35, בריטניה 3:40, שוודיה 3:45, נורווגיה 3:50.
- מעבורות: נמל סודה לפיראוס (אתונה); נמל רתימנו לסנטוריני ומילוס; נמל הרקליון לסנטוריני, מיקונוס ואיים נוספים; נמל קיסאמוס (קסטלי) לקיתירה ואנטיקיתירה.

### 2.3 מתקני הריזורט
- בריכת אינסוף משותפת 10×4 מ׳ על שפת הצוק, ג׳קוזי ל־8 אנשים, בר, מטבח חוץ, טרקלינים.
- ספא וולנס: חדר כושר, סאונה יבשה עם קירות זכוכית (עד כ־6 אנשים), חדר טיפולים, מרחב ליוגה, פילאטיס ומדיטציה.
- מעלית זכוכית פנורמית מהכניסה העליונה למפלס הבריכה והריזורט.
- חניה עליונה, כ־9 מקומות ו־2 עמדות טעינה לרכב חשמלי; שירותים לאורחים בקומת הבריכה.
- תאורה אדריכלית, גינון ים־תיכוני, השקיה אוטומטית, ניהול מרחוק של תאורה ובקרת כניסה.

### 2.4 מפרט וילה (Turnkey)
עיצוב פנים מלא של אדריכל ומעצבת פנים; ריהוט מיובא; מטבח מלא (Bosch, Sauter או שווה ערך); בריכה פרטית בסגנון אינפיניטי; מטבח חוץ עם גריל; טלוויזיה מעל 50 אינץ׳ בסלון ומעל 45 אינץ׳ בכל חדר שינה; ריצוף פורצלן 120×60; בידוד תרמי מעל התקן; מיזוג אינוורטר בכל חדר; מערכת חכמה למחצה עם שליטה ב־Wi-Fi; דלת ביטחון רב־בריחית עם טביעת אצבע, קוד או זיהוי פנים; מוכנות מלאה להשכרה קצרת טווח.

### 2.5 ניהול והשכרה (Sivan Management)
ניהול השטחים המשותפים, גינון, תחזוקת וילות, ניקיון והכנה לאורחים, ניהול השכרה ותשואה (Booking, Airbnb, תמחור דינמי), שקיפות לבעלים באפליקציה, תיאום רגולטורי ופיננסי, קונסיירז׳ (שף פרטי, הסעות, השכרת רכב, הזמנות, טיפולי ספא).

### 3.2 עיצוב ו־UX
- **סגנון:** בהשראת אפל. רקע שנהב #FAF8F4, דיו #1C1A16, זהב #C6A15C, וזהב לטקסט #86652A לניגודיות AA. קווים דקים, פינות 16px, כפתורים בצורת גלולה, כותרת עליונה מזכוכית מטושטשת.
- **גופנים** (מאוחסנים על השרת, בלי Google Fonts, לטובת GDPR): Cormorant Garamond ו־Inter (לטינית), Noto Serif Display ו־Inter (יוונית), Frank Ruhl Libre ו־Heebo (עברית), Amiri ו־IBM Plex Sans Arabic (ערבית).
- **תנועה:** וידאו רקע, שכבות פרלקס, כותרת שנחשפת מילה אחר מילה, טקסט שמואר מילה אחר מילה בגלילה, תמונה שמתרחבת למסך מלא, גלילה אופקית נעוצה, סיפור נעוץ, מוני מספרים, מרקיז, סליידר עם גרירה, Lightbox, לשוניות, סינון. הכול מכבד את ההגדרה "הפחתת תנועה".
- **לוגו:** הכתר הומר לקובץ וקטורי (SVG) בזהב, לבן ושחור. ממנו נוצרו favicon, אייקונים ותמונת שיתוף (OG).
- **נגישות:** תפריט נגישות (גודל טקסט, ניגודיות, עצירת תנועה, הדגשת קישורים, גופן קריא), דילוג לתוכן, ניווט מלא במקלדת, תמיכה ב־RTL.

### 3.3 קידום אורגני ו־AI
- כותרת ותיאור ייחודיים לכל עמוד בכל שפה, עם מילות מפתח מקומיות.
- hreflang לכל 7 השפות ו־x-default, כתובת קנונית, תגיות Open Graph ו־Twitter.
- נתונים מובנים (JSON-LD): Organization/RealEstateAgent, ApartmentComplex, Accommodation, FAQPage, BreadcrumbList, ImageGallery. בלי מחירים.
- sitemap.xml עם קישורים בין השפות ותמונות, robots.txt שמתיר סורקי AI (GPTBot, ClaudeBot, Perplexity, Google-Extended), llms.txt לסיכום הפרויקט למנועי AI.

### 3.4 תאימות (EU וישראל)
- **עוגיות:** באנר שבו דחייה קלה כמו הסכמה, הגדרה לפי קטגוריות, Google Consent Mode v2 (הכול חסום עד הסכמה), שמירת ההסכמה ל־12 חודשים, וקישור "הגדרות עוגיות" בפוטר.
- **טפסים:** הסכמה למדיניות הפרטיות היא חובה; הסכמה לדיוור לא מסומנת מראש (סעיף 30א, חוק הספאם).
- **פרטיות:** העברה למשרד בישראל מבוססת על החלטת הלימות של האיחוד האירופי.

### 3.5 טפסים ולידים
- הנתיב `/api/lead.php` (PHP 8 ומעלה): אימות שדות, honeypot נגד ספאם, הגבלת קצב (5 פניות ל־10 דקות לכל IP), בדיקת מקור, וקליטת UTM ו־gclid.
- נמענים: `KS_LEAD_TO` (ברירת מחדל support@sivaninvestgroup.com) ו־`KS_LEAD_CC` (ברירת מחדל sivanmen@gmail.com).
- אופציונלי: `KS_LEAD_WEBHOOK` שולח כל ליד כ־JSON ל־CRM (Make, Zapier, HubSpot, Monday).
- אם שליחת המייל נכשלת, הליד נשמר ב־`api/storage/leads-fallback.jsonl`, תיקייה חסומה לגישה מהדפדפן.

| `data/images.json` | מניפסט התמונות (נוצר אוטומטית) |
| `build/` | מחולל האתר: Node, בלי תלויות חיצוניות |
| `static/css`, `static/js`, `static/api` | מקורות העיצוב, האינטראקציות וטופס ה־PHP |
| `scripts/` | אופטימיזציית תמונות, הורדת גופנים, נכסי מותג, בדיקת איכות, הורדת מקורות |
| `assets-src/` | קבצי מקור מקוריים (לא נשמרים ב־Git; משחזרים עם `scripts/fetch-assets.sh`) |

### 4.2 פעולות שוטפות
- **עדכון סטטוס וילה:** עורכים את `status` ב־`data/project.json` (available / reserved / sold) ומריצים בנייה.
- **עדכון טקסט:** עורכים את `content/<lang>/<file>.json`, אותו מפתח בכל השפות.
- **הוספת מזהי מדידה:** ב־`data/config.json` תחת `tracking` (ga4, googleAds, metaPixel, gtm). הם נטענים רק אחרי הסכמה לעוגיות.
- **בנייה ובדיקה:**

```bash
cd sites/kingsolomoncrete && npm run build && npm run check
```

- **תמונות חדשות:** שמים קובץ ks-name.webp ב־`assets-src/img/` ומריצים:

```bash
python3 -I scripts/optimize-images.py assets-src/img dist/assets/img
```

### 4.4 העלאה לשרת
1. מפנים את הדומיין ל־hosting ומפעילים SSL.
2. מעלים את **תוכן** התיקייה `dist/` לתיקיית השורש של האתר (public_html).
3. ב־Apache הקובץ `.htaccess` כבר מוכן: הפניה ל־HTTPS ול־www, Cache, דחיסה, Security headers ו־CSP. ל־nginx יש דוגמה ב־`nginx.conf.example`.
4. מגדירים בשרת את המשתנים KS_LEAD_TO, KS_LEAD_CC, KS_LEAD_FROM, ובמידת הצורך KS_LEAD_WEBHOOK.
5. מגישים את sitemap.xml ל־Google Search Console ול־Bing Webmaster.
6. שולחים ליד בדיקה מהאתר החי ומוודאים שהמייל הגיע לשתי הכתובות.
